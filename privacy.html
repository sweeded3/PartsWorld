Политика конфиденциальности

Краткая версия для учебного статического сайта Parts World.

Какие данные используются

Форма на сайте может содержать имя, телефон, VIN, сообщение и название выбранного файла. Эти данные нужны только для подготовки текста заявки.

Как работает форма

Сайт размещается как статический проект и не имеет собственного сервера для хранения заявок. При отправке формы браузер открывает WhatsApp с уже заполненным сообщением. Если выбран файл, его нужно прикрепить в WhatsApp вручную.

Сторонние сервисы

На сайте используются внешние ресурсы: шрифты Google Fonts, иконки Font Awesome, карта OpenStreetMap и WhatsApp/email для связи. Эти сервисы могут обрабатывать технические данные пользователя в соответствии со своими правилами.
